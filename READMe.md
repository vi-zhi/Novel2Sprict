# Novel2Script - 小说转剧本智能转换系统

## 📖 项目简介

Novel2Script 是一个基于 AI 的智能转换系统，能够将小说文本自动转换为专业的剧本格式。该系统利用先进的 AI 模型和自然语言处理技术，分析小说结构、提取关键元素，并按照行业标准格式生成剧本。

## 🚀 主要特性

- **智能分析**: 自动分析小说结构，提取角色、场景、情节等关键信息
- **专业转换**: 将小说内容转换为符合行业标准的剧本格式
- **多格式支持**: 支持 TXT 文本文件和直接文本输入
- **AI 驱动**: 基于 Google ADK 和 Spring AI 框架，使用火山引擎 AI 模型
- **RESTful API**: 提供标准化的 REST API 接口
- **微服务架构**: 采用 DDD 领域驱动设计，模块化架构

## 🏗️ 技术栈

- **Java 17** - 主要编程语言
- **Spring Boot 3.4.3** - Web 框架
- **Spring AI 1.1.0-M3** - AI 集成框架
- **Google ADK 1.1.0** - AI 开发套件
- **MySQL 8.0** - 数据库
- **Maven** - 构建工具

## 📡 API 接口

### 1. 文本转换接口

**端点**: `POST /api/novel2script/convert`

**请求体**:

json {
    "userId": "user123", 
    "novelTitle": "我的小说",
    "novelContent": "这里是小说内容...",
    "convertStyle": "standard" 
}
**响应**:
json { 
    "scriptContent": "转换后的剧本内容", 
    "analysisResult": "分析结果",
    "sceneCount": 5, 
    "characterList": ["角色1", "角色2"]
}

### 2. 文件上传接口

**端点**: `POST /api/novel2script/convert/file`

**请求参数**:
- `file`: TXT 格式的小说文件
- `userId`: 用户ID（可选）
- `title`: 小说标题（可选）
- `style`: 转换风格（可选）

## 🤖 AI Agent 工作流程

系统采用三阶段 AI Agent 工作流：

1. **analyzeNovel** - 小说分析
   - 提取角色列表及特征
   - 识别场景（时间、地点）
   - 梳理情节发展脉络
   - 提取对话内容
   - 标记动作描写

2. **convertToScript** - 剧本转换
   - 生成场景标题（内/外.地点-时间）
   - 转换动作为视觉化描述
   - 格式化对话内容
   - 删除心理描写和旁白

3. **optimizeScript** - 剧本优化
   - 检查格式规范性
   - 优化场景转换
   - 提升对话自然度
   - 添加转场说明
